## ภาพรวมของระบบ

ภายในเกม Wuthering Waves ไฟล์วิดีโอคัตซีนที่ถูกแยกออกมาจากฐานข้อมูลของตัวเกมจะไม่มีบทบรรยายฝังในตัว ไม่มีเสียงพากย์ของตัวละคร และไม่มีการผสมผสานดนตรีประกอบฉากแบบสมบูรณ์ เสียงพากย์และเสียงประกอบทั้งหมดถูกจัดเก็บแยกอยู่ภายในคลังเสียงเฉพาะ Audiokinetic Wwise SoundBanks ขณะที่บทสนทนาและคำอ่านรูบี้ถูกกระจายอยู่ในฐานข้อมูลข้อความหลายภาษา

WuWa Cutscene Studio ทำหน้าที่เป็นสะพานเชื่อมต่อกระบวนการผลิตทั้งหมดแบบอัตโนมัติบนเดสก์ท็อป:
- ค้นหาและทำดัชนีคัตซีนจากโครงสร้างโฟลเดอร์ของเกมอย่างรวดเร็ว
- วิเคราะห์และถอดรหัสคลังเสียง Wwise พร้อมจับคู่เสียงพากย์หลายภาษาทั้งภาษาญี่ปุ่น ภาษาอังกฤษ ภาษาเกาหลี และภาษาจีน
- วางตำแหน่งบทสนทนาและคำอ่านรูบี้ด้วยสมการคำนวณทางคณิตศาสตร์ที่แม่นยำระดับพิกเซล
- เรนเดอร์วิดีโอคุณภาพสูงด้วยการเร่งความเร็วผ่านการ์ดจอโดยเอนจิน FFmpeg

## จุดเด่นสำคัญของระบบ

### 1. ระบบค้นหาสินทรัพย์อัจฉริยะและการแสดงผลตัวอย่างทันที
- การสแกนแบบ Zero-Extract ค้นหาคัตซีนและจับคู่คลังเสียงที่เกี่ยวข้องได้ทันทีโดยไม่ต้องคลายไฟล์ขนาดใหญ่ล่วงหน้า
- แสดงข้อมูลทางเทคนิคของวิดีโอ ความยาว ความละเอียด อัตราเฟรมภาพ และภาพตัวอย่างขนาดย่อแบบเรียลไทม์
- คัดกรองและสลับไฟล์เสียงตามเพศของตัวละครหลัก โรเวอร์หญิง หรือ โรเวอร์ชาย ได้อย่างแม่นยำ
- ระบบแจ้งเตือนช่วยเหลือผู้ใช้เมื่อตรวจพบว่ายังไม่ได้ตั้งค่าโฟลเดอร์ หรือไฟล์เสียงไม่สมบูรณ์

### 2. ท่อส่งข้อมูลเสียง Wwise และการมิกซ์เสียงหลายแทร็ก
- ถอดรหัสโครงสร้างคลังเสียง Wwise โดยการประสานงานระหว่าง Wwiser และ vgmstream เพื่อแปลงไฟล์เสียง Opus ความถี่ 48kHz
- สลับภาษาเสียงพากย์ได้ทันที ทั้งภาษาญี่ปุ่น ภาษาอังกฤษ ภาษาเกาหลี และภาษาจีน
- แปลงระบบเสียงรอบทิศทาง 5.1 แชนเนล เป็นระบบเสียงสเตอริโอ 2 แชนเนล พร้อมชดเชยเฟสเสียงและเพิ่มความชัดเจนของเสียงพูดตรงกลาง
- ระบบควบคุมระดับเสียงสูงสุดอัตโนมัติเพื่อป้องกันเสียงแตกพร่าจากการซ้อนทับกันหลายชั้นเสียง

### 3. ห้องทดลองตัวพิมพ์และสตูดิโอบทบรรยาย
- ระบบจัดตำแหน่งคำอ่านรูบี้สองบรรทัด คำนวณพิกัดแนวนอนให้ตรงกับคำศัพท์เป้าหมายอย่างแม่นยำโดยไม่มีการเยื้องหลุดตำแหน่ง
- การสอบเทียบอัตราส่วนฟอนต์ของเอนจิน libass ด้วยค่าคงที่ 0.635 เพื่อให้ภาพพรีวิวบนหน้าจอตรงกับวิดีโอที่เรนเดอร์จริงทุกประการ
- กล่องแสดงเนื้อเพลงมุมบนซ้ายที่สามารถปรับขนาดตัวอักษร ระยะห่างระหว่างบรรทัด ขอบเขต และความหนาของเส้นขอบได้อย่างอิสระ
- เส้นบอกระยะปลอดภัยตามมาตรฐานความปลอดภัยสำหรับการจัดวางภาพบนจอภาพ 90 เปอร์เซ็นต์
- ชุดรูปแบบตัวอักษรสำเร็จรูป การกำหนดขนาดตัวอักษร ความหนาของเส้นขอบ ความลึกของเงา และระยะห่างจากขอบล่าง

### 4. เอนจินปรับขนาดความละเอียดและสัดส่วนภาพ
- ปรับสัดส่วน 16 ต่อ 9 เต็มหน้าจอ โดยการขยายและตัดขอบภาพอัลตราไวด์ 21 ต่อ 9 ตรงกึ่งกลางโดยไม่มีขอบสีดำ
- สัดส่วนอัลตราไวด์ 21 ต่อ 9 ดั้งเดิม พร้อมแถบสีดำด้านบนและด้านล่างตามต้นฉบับภาพยนตร์
- สัดส่วนดั้งเดิมของตัวเกม รักษาความละเอียดต้นฉบับโดยไม่มีการบีบหรือยืดภาพ
- ความละเอียดสูงพิเศษ 4K สำหรับการจัดเก็บไฟล์คุณภาพสูง

## กระบวนการจัดการระบบเสียง Wwise

เหตุผลที่บางคัตซีนมีเสียงพากย์และเสียงประกอบเอฟเฟกต์ แต่ไม่มีดนตรีประกอบฉาก

```
+----------------------------------------------------------------------------------+
|                            สถาปัตยกรรมระบบเสียงของเกม                            |
+----------------------------------------------------------------------------------+
|                                                                                  |
|   คัตซีนภาพยนตร์เรื่องราวหลัก                                                    |
|   คลังเสียงภาพยนตร์เฉพาะ                                                         |
|   แทร็กเสียงพูดตัวละคร ------------------+                                        |
|   แทร็กเสียงเอฟเฟกต์ --------------------+---> สกัดและมิกซ์รวมดนตรีประกอบสมบูรณ์ |
|   แทร็กดนตรีประกอบเฉพาะฉาก --------------+                                        |
|                                                                                  |
|   คัตซีนเควสต์ภายในฉากเกม                                                        |
|   คลังเสียงเฉพาะคัตซีน                                                           |
|   แทร็กเสียงพูดตัวละคร ------------------+                                        |
|   แทร็กเสียงเอฟเฟกต์ --------------------+---> สกัดเฉพาะเสียงพูดและเสียงเอฟเฟกต์ |
|                                                                                  |
|   สถานะเสียงดนตรีสดในโลกของเกม                                                   |
|   ตัวควบคุมดนตรีแผนที่และการต่อสู้                                               |
|   เล่นแบบไดนามิกตามสภาพแวดล้อมขณะเล่นเกมจริง                                     |
|                                                                                  |
+----------------------------------------------------------------------------------+
```

1. คลังเสียงเฉพาะของภาพยนตร์: คัตซีนสำคัญที่มีการประพันธ์ดนตรีขึ้นมาเฉพาะฉากนั้น ดนตรีจะถูกบรรจุอยู่ภายในคลังเสียงโดยตรง ระบบจะทำการสกัดและมิกซ์เสียงทุกชั้นรวมถึงดนตรีประกอบโดยอัตโนมัติ
2. ฉากเควสต์ภายในเอนจินของเกม: คัตซีนภารกิจทั่วไปจะอาศัยระบบดนตรีพลวัตของตัวเกม ดนตรีประกอบจะเล่นต่อเนื่องมาจากสภาพแวดล้อมของแผนที่โลก จึงไม่มีดนตรีบันทึกอยู่ในคลังเสียงของฉากนั้น
3. การจับคู่ดนตรีประกอบฉาก: ระบบมีการสแกนหาความเชื่อมโยงของชื่อดนตรีเพื่อนำไฟล์ดนตรีที่เกี่ยวข้องมามิกซ์รวมกันในกรณีที่มีข้อมูลการจับคู่ระบุไว้

## ขั้นตอนการเริ่มต้นใช้งาน

### การติดตั้งโปรแกรม

1. ดาวน์โหลดไฟล์ติดตั้งรุ่นล่าสุดจากหน้า <a href="https://github.com/Ma3-OS/wuwa-cutscene-studio/releases">Releases</a>
2. เปิดไฟล์ติดตั้งสำหรับระบบปฏิบัติการ Windows 10 หรือ 11 รุ่น 64 บิต
3. เปิดโปรแกรม WuWa Cutscene Studio

### การตั้งค่าและการใช้งาน

1. การซิงค์ระบบ: ไปที่แท็บการตั้งค่า แล้วกดปุ่มซิงค์เครื่องมือและข้อมูล เพื่อดาวน์โหลดโปรแกรมและฐานข้อมูลที่จำเป็นแบบอัตโนมัติ
2. กำหนดโฟลเดอร์ไฟล์เกม: ระบุตำแหน่งโฟลเดอร์ที่มีโครงสร้างข้อมูลของเกมที่สกัดไว้
3. ปรับแต่งบทบรรยาย: เลือกแบบอักษร ขนาดตัวอักษร ความหนาเส้นขอบ และตำแหน่งคำอ่านรูบี้ในหน้าสตูดิโอบทบรรยาย
4. เลือกและเรนเดอร์: ในหน้าแกลเลอรี เลือกคัตซีนที่ต้องการ กำหนดภาษาของเสียงพากย์และเพศของตัวละคร แล้วกดเริ่มการประมวลผล

## คู่มือสำหรับนักพัฒนา

### สิ่งที่จำเป็นต้องมีในระบบ
- ระบบปฏิบัติการ Windows 10 หรือ 11 แบบ 64 บิต
- Node.js รุ่น 20 ขึ้นไป พร้อมระบบ npm
- ภาษา Rust รุ่นเสถียรสำหรับคอมไพเลอร์เป้าหมาย x86_64-pc-windows-msvc
- ภาษา Python รุ่น 3.10 ขึ้นไปสำหรับเครื่องมือ Wwiser

### การคอมไพล์โปรแกรมจากโค้ดต้นฉบับ

```powershell
# 1. โคลนคลังโค้ด
git clone https://github.com/Ma3-OS/wuwa-cutscene-studio.git
cd wuwa-cutscene-studio

# 2. ติดตั้งโมดูลส่วนติดต่อผู้ใช้
npm install

# 3. รันโปรแกรมในโหมดพัฒนา
npm run tauri dev

# 4. คอมไพล์เป็นตัวติดตั้งสำหรับแจกจ่าย
npm run tauri build
```

### การตรวจสอบคุณภาพโค้ดก่อนส่งมอบ

```powershell
# ตรวจสอบความถูกต้องของโค้ดภาษา Rust
cargo check --manifest-path src-tauri/Cargo.toml

# รันชุดทดสอบความแม่นยำของบทบรรยายและรูบี้
cargo test --manifest-path src-tauri/Cargo.toml subtitles

# ตรวจสอบความถูกต้องของ TypeScript และบิลด์หน้าบ้าน
npm run build

# ตรวจสอบความปลอดภัยและไฟล์คัดกรองก่อนเผยแพร่
python scripts/pre_publish_audit.py
```

## เทคโนโลยีที่ใช้งาน

- โครงสร้างโปรแกรมเดสก์ท็อป: Tauri v2
- ส่วนติดต่อผู้ใช้: React 19 ร่วมกับ TypeScript และ Tailwind CSS v4
- การจัดการภาพเคลื่อนไหวและไอคอน: Lucide Icons และ Framer Motion
- การประมวลผลมัลติมีเดีย: FFmpeg vgmstream และ Wwiser
- เอนจินบทบรรยาย: libass ร่วมกับรูปแบบ Advanced SubStation Alpha

## กิตติกรรมประกาศและเครดิตผู้พัฒนา

โปรเจกต์นี้สำเร็จลุล่วงได้ด้วยผลงานและการค้นคว้าอันยอดเยี่ยมของชุมชนโอเพนซอร์ส นักวิจัยข้อมูลเกม และเครื่องมือมัลติมีเดียระดับแนวหน้า ขอขอบคุณทุกท่านดังต่อไปนี้:

- <a href="https://wutheringwaves.kurogames.com/">Kuro Games</a>: ผู้สร้างสรรค์และผู้ถือลิขสิทธิ์เกม Wuthering Waves สินทรัพย์ภาพ เสียง วิดีโอ และเนื้อหาทั้งหมดเป็นทรัพย์สินทางปัญญาของ Kuro Games แต่เพียงผู้เดียว
- <a href="https://github.com/Hiro420">Hiro420</a>: ผู้พัฒนา <a href="https://github.com/Hiro420/WuwaTools">WuwaTools</a> ผู้วางรากฐานการวิเคราะห์โครงสร้างฐานข้อมูล SQLite ConfigDB และกระบวนการแปลง Base64 BinData เพื่อการสกัดข้อความแบบออฟไลน์
- <a href="https://github.com/Arikatsu">Arikatsu</a>: ผู้ดูแลคลังข้อมูล <a href="https://github.com/Arikatsu/WutheringWaves_Data">WutheringWaves_Data</a> ผู้วางโครงสร้างมาตรฐานการจัดเก็บไฟล์ BinData และตารางข้อความหลายภาษา Textmaps
- <a href="https://github.com/FabianFG/CUE4Parse">Fabian และผู้มีส่วนร่วมพัฒนา CUE4Parse</a>: ไลบรารีประสิทธิภาพสูงสำหรับวิเคราะห์แพ็กเกจ Unreal Engine PAK และ VFS เพื่อการสกัดข้อมูลโดยตรง
- <a href="https://github.com/bnnm/wwiser">bnnm และผู้มีส่วนร่วมพัฒนา Wwiser</a>: โปรแกรมถอดรหัสโครงสร้าง SoundBank ของ Wwise และสร้างโครงข่ายเสียง txtp
- <a href="https://github.com/vgmstream/vgmstream">ทีมผู้พัฒนา vgmstream</a>: โปรแกรมแปลงไฟล์เสียง wem คุณภาพสูงเป็นสัญญาณเสียงแบบไม่สูญเสียคุณภาพ
- <a href="https://ffmpeg.org/">ทีมผู้พัฒนา FFmpeg</a>: โครงสร้างหลักสำหรับการเรนเดอร์วิดีโอ การแปลงระบบเสียงรอบทิศทาง และการฝังบทบรรยาย
- <a href="https://github.com/libass/libass">โปรเจกต์ libass</a>: เอนจินเรนเดอร์บทบรรยายมาตรฐาน Advanced SubStation Alpha ที่รองรับการคำนวณพิกัดระดับทศนิยม
- <a href="https://fmodel.app/">ชุมชนผู้พัฒนา FModel</a>: ชุดเครื่องมือสำรวจโครงสร้างและไฟล์สินทรัพย์ของ Unreal Engine
- <a href="https://v2.tauri.app/">ทีมงาน Tauri</a> และ <a href="https://www.rust-lang.org/">โครงการภาษา Rust</a>: สถาปัตยกรรมแอปพลิเคชันเดสก์ท็อปที่รวดเร็ว ปลอดภัย และประหยัดหน่วยความจำ

สามารถอ่านรายละเอียดกิตติกรรมประกาศฉบับเต็มได้ที่เอกสาร <a href="CREDITS.md">CREDITS.md</a>
